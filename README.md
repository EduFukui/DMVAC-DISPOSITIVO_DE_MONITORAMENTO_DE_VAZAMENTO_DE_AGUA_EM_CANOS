# DMVAC-DISPOSITIVO_DE_MONITORAMENTO_DE_VAZAMENTO_DE_AGUA_EM_CANOS
O DMVAC é um dispositivo para monitoramento de vazamentos de água em canos. Utiliza sensores de fluxo e um ESP32 para identificar alterações na vazão e acionar uma válvula solenoide. O sistema também permite o acompanhamento dos dados por uma plataforma online, buscando reduzir desperdícios e danos.
